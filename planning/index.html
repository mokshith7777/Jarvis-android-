05 / ARCHITECTURE MAP

Five connected domains.

Keep interfaces clean so individual pieces can evolve without forcing rewrites across the entire app.

◉

Experience

Conversation, voice, widgets, accessible feedback, settings and user context.

⌘

Orchestration

Intent, planning, tool selection, policy checks, task state and result synthesis.

◇

Models

▤

Memory

Local data, conversation history, optional retrieval and user-controlled retention.

⌁

Android Bridge

Permission-bound system features, app integrations, background work and notifications.

⛨

Trust Boundary

Secrets, confirmation gates, input validation, logging discipline and recovery.
